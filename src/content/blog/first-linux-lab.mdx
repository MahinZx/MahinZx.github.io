I started exploring Linux through Ubuntu on WSL2, keeping Windows as my main operating system while practising in a separate Linux environment.

## Small commands, real lessons

I began with `whoami`, `pwd`, `ls -la` and `cat` to understand users, directories and files. Then I used `nano` to edit scripts and `chmod` to learn about permissions.

## A first Bash script

My `disk-check.sh` experiment showed filesystem usage with `df -h`. It wasn't a production monitoring system; it was a way to connect commands to something observable.

I'm documenting what I actually try, not presenting a finished DevOps lab. There's more to learn.
