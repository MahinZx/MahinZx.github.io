## A small application with useful fundamentals
This Python desktop application uses Tkinter to present weather information through a graphical interface. The project brings together object-oriented programming, design patterns, input validation, error handling, and testing.

## Engineering focus
A weather interface must handle more than the successful response. User input can be invalid and a weather request can fail. Separating interface behaviour from application logic makes those paths easier to reason about and test.

## Learning through implementation
The project provides hands-on practice with structuring Python classes and giving users understandable feedback. It is presented as a learning project without invented test-coverage figures or performance claims.
