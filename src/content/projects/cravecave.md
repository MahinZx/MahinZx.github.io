## One platform, several perspectives
CraveCave is a substantial university development project built around the different people involved in a food delivery order: customers, restaurants, drivers, and administrators.

## Technology and structure
Spring Boot and REST APIs support the backend. JavaFX provides a desktop interface for restaurant and administrative workflows, while web interfaces serve customers and drivers. MySQL stores the application's relational data.

## What the project covers
- Authentication and multiple user roles.
- Restaurant and administrator workflows.
- Customer ordering and order management.
- Driver-facing delivery workflows.

## Engineering focus
The central design challenge is keeping several interfaces aligned around the same order and its changing state. The project is a practical setting for applying object-oriented programming, separating interface logic from backend responsibilities, and designing relationships in a database.

This is academic development work. It is not presented as a commercial delivery service, and no public deployment or performance benchmark is claimed.
