## Learning systems from the inside
An ongoing home-lab learning project using Ubuntu on WSL2. The aim is to understand everyday Linux administration through small, practical tasks.

## Current scope
- Navigating the filesystem and understanding paths.
- Working with Linux permissions.
- Writing and understanding Bash scripts.
- Exploring basic disk monitoring.
- Building system administration fundamentals.

## Next directions
Continue documenting repeatable tasks and explore infrastructure concepts gradually. Docker fundamentals are part of the learning path.

Kubernetes, Terraform, and production AWS infrastructure are future possibilities, not completed work. This project is explicitly in progress.
