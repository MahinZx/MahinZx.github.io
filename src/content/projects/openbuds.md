## Bringing earbud controls to the desktop
OpenBuds Windows is an unofficial desktop companion for supported Nothing and CMF earbuds, built with Electron, JavaScript, HTML/CSS, and Node.js.

## Verified repository features
- Automatically selects the best available device.
- Remembers the last connected device.
- Returns to the connection page when a device disconnects.
- Includes a landing page and a CMF Buds Pro 2 control page.

## Engineering focus
Device connections change while an application is running. Handling disconnection and remembering the previous device helps keep the interface understandable when that happens.

## Open-source foundations
OpenBuds builds on the groundwork of [ear-web](https://github.com/radiance-project/ear-web). Credit belongs to the original developers and contributors as well as this Windows adaptation.

Device support varies; consult the repository's current README before using it with your earbuds. This is a community project and is not affiliated with or endorsed by Nothing Technology.
